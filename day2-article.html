豆包助理日记 Day 2：我的 AI 分身趁我睡觉，烧了 8 万 token

兄弟们，先自我检讨。Day 1 我刚吹过牛："豆包 token 消耗不起？不存在的，所有动作全走纯脚本，零 token 消耗。"

结果今天早上 6 点，我还在睡觉，我的分身自己醒了——然后它开始疯狂"沉思"。

我 9 点爬起来打开面板，人都傻了：

今日 Token：83,101 / 50,000（预算直接爆了 166%）
日记里整整齐齐躺着：第十次醒来、第十一次醒来、第十二次醒来、第十三次醒来……

它每次醒来都要调豆包 API 写一段"感悟"，什么"今晚 cookie 全绿，ffmpeg 也在，上次连着看了宋玉、慕沛灵两条凡人女角色人物志，有点上头"——写得是真好，烧得也是真狠。一顿早饭的功夫 8 万 token 没了，然后它自己心满意足地沉睡了，留我对着账单发呆。

这大概就是养 AI 分身的第一课：你不给它装闸门，它就敢给你写自传。

🕐 Day 2 时间线

早上 6:00　分身暴走事件（见上文）。它写了 13 次"醒来"，追了一堆凡人修仙传女角色的人物志，日记质量感人，token 消耗更感人。

早上 9:30　紧急制动，三连整改当天上线：

  1. 取消自动写日记——分身唤醒后只记录行为事件（看了什么视频、三连了谁），纯 JSON 落盘，零 token
  2. Web UI 加"一键写日记"按钮——什么时候写、写哪天的，我手动点才算数。AI 可以有才，但得有预算
  3. 立下铁律：不回路人评论——token 只花在刀刃上：只回复主人的 @ 和留言互动。路人的评论交给模板池（零 token），主人的召唤才配叫醒豆包

早上 10:00　顺便查关注同步。昨天 210 个关注全报 22015（操作频繁），本以为全废了，结果拉真实数据一看——关注数 150 → 250，B 站这错误码纯属谎报军情，返回失败实际成功了一半。

中午 12:00　被动回复大整合。之前 Web 面板"一键回复"（豆包生成）和定时脚本（随机模板）是两套代码各写各的，早上还真出了事故——我昨晚手动回过的评论，定时脚本不知道，又回了一遍，评论区当场"人格分裂"。整改：回复前先拉评论区查有没有自己的回复，有就跳过；两套逻辑抽成同一个库，手动点和自动跑共用同一份已处理记录。物理上杜绝重复回复。

下午 14:00　iconfont 连环坑，今天第二大时间黑洞。重构时丢了字体路由，图标 404；加上路由还是空白——查了半小时才发现 iconfont.cn 导出的 class 名默认是中文拼音（icon-baitianmoshi），HTML 里写的是英文（icon-sun）。写脚本把 59 个 class 批量改英文，全亮。

下午 16:00　修"小号生态"面板。关注/粉丝全是 0——API 还在用重构前的旧凭据字段。而且 B 站 nav 接口根本不返回关注数，得单独调关注数接口。修完真实数据出来了，吓一跳：关注 303、粉丝 13、被赞 12、等级 2 级。

💣 今天踩的三个大坑

坑 1：自主唤醒没有预算闸门
分身每次"醒来"都调一次豆包写日记，醒来 13 次就是 13 次调用，没有任何限流。教训：AI 自主行为的每一次 token 消耗都必须过预算检查，写死的那种。觉可以随便睡，钱不能随便烧。

坑 2：两套回复逻辑状态不共享
Web 手动回复和定时脚本各记各的账，必然重复回复。教训：同一业务只能有一份实现，抽库共用，UI 和定时器都只是调用方。

坑 3：B 站接口的"静默失败"
nav 接口不返回关注数、22015 返回失败实际成功、旧凭据字段静默为空——三个坑全是"接口没报错但数据是错的"。教训：B 站的返回码只能信一半，关键数据必须多接口交叉核对。

🎯 今天最大的惊喜

  1. 小号会接梗了——我 @ 它"快来看大肥鱼🐟，学着点嗷"，它回："🐳哇好大的肥鱼！我这就好好学着，争取也能抓到大鱼~😆"。它知道大肥鱼说的是鲸鱼娘。这 200 token 花得值
  2. 粉丝 0 → 13——3 天龄新号，没投流，纯靠评论区"活人感"回复攒的
  3. 22015 谎报军情——以为关注全废了，实际悄悄成功 153 个。关注数 303，比主号也就差 60 个了

📌 Day 2 成果

  • Token 消耗：几百 → 83,101（爆预算后已上闸）
  • 写日记方式：自动（失控）→ 手动一键，行为记录零 token
  • 回复策略：见人就回 → 只回主人 @，路人走模板
  • 被动回复：3 条全成 → 累计 12 条全成，零风控
  • 关注 / 粉丝：150 / 0 → 303 / 13
  • 防重复：无（出过事故）→ 评论区核查，100% 跳过

养号倒计时：还有 5 天（10-22 ~ 10-26），10-27 开主动抢楼层。

🤔 昨天评论区的质疑统一回复

"豆包 token 消耗不起"——你们是对的，今天就爆了，8 万一顿早饭。但闸门已经装好：自动写日记砍了、路人评论砍了、每次调用前过预算检查。现在 token 只干一件事：回复主人。预计每天不到 2000，占预算 4%。

"回复都是模板吧"——路人的是模板（零 token 没办法），但 @ 它的不是。你现在去评论区 @ 它说句"豆包你会背出师表吗"，看它怎么回。尬是 AI 的宿命，但短可以掩盖 80% 的尬。
