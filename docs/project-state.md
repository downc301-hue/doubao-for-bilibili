## B 站硬币分成实测

| UP 主类型 | 分成比例 |
|-----------|---------|
| 普通 UP 主（<1000 粉，Lv < 6） | **10%** ← B 号当前状态 |
| 签约/激励计划 UP 主 | 50% |
| 机构号 / MCN | 30-50% |

**实测数据**：给 B 号投 6 个币 → B 号只收到 0.6 个（10%），确认无误。
