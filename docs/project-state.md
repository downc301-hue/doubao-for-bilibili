## 💰 Token 消耗估算（基于用户实测 + lite 模型）

**豆包 lite 模型真实价格**：输入 0.15 + 输出 0.6 = **0.75 元/百万 tokens（输入输出合计）**

| 项目 | 数值 |
|------|------|
| 新用户免费额度 | 500,000 tokens = 0.375 元 |
| 用户已充值 | 2 元 ≈ 2,666,666 tokens |
| 每款模型各自有免费额度 | 是（豆包全系） |

**优化后的每天消耗（lite 模型）**：

| 环节 | 估算 tokens | 优化点 |
|------|------------|--------|
| System Prompt | ~800 | 精简人设，固定开销 |
| 读昨天的日记（模拟"记忆"） | ~1,500 | 不累积对话历史，每次读文件 |
| feed 选题（5条，预处理后） | ~2,500 | 截断字幕/弹幕到关键片段 |
| debrief 深读（2条，lite 跑） | ~6,000 | 预处理后塞给 AI |
| 写两本日记 | ~3,500 | |
| Function Call 循环开销 | ~2,000 | 精简 tool 返回值 |
| **每天合计** | **~16,300 tokens** | |
| **充 2 块钱能用** | **≈ 163 天** | |
| **月均费用** | **≈ 0.33 元** | |

> 用户之前烧得快的原因：多轮对话累积历史（没做 summary）+ 可能 Function Call 循环放大。我们从架构上掐这两个浪费源。
